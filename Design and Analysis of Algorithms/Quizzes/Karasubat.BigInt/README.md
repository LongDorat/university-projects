# Karasubat

## Bash (Linux/macOS)

```bash
./Run.sh
./Run.sh --range 4
./Run.sh --positive-only
./Run.sh -r 3 -p
```

## PowerShell

```powershell
./Run.ps1
./Run.ps1 -Range 4
./Run.ps1 -PositiveOnly
./Run.ps1 -Range 3 -PositiveOnly
```

## Notes

- The random magnitude range is [10^r, 9*10^r].
- Use LF line endings for Run.sh on Linux.
