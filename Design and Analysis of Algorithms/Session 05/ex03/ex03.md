## Question 6

Quick selection is an algorithm to find the k smallest element in an ordered array. The algorithm is similar to quick sort that after the pivot is found, the algorithm recurs only the part which contains the k smallest element. Compute the complexity of the algorithm in 3 cases:

### Best case:

In the beginning, we scan all $n$ elements to find the pivot, takes $n$ operations. The pivot either lands exactly on the $k$-th element, or it splits the array into two equal halves. In the first case, we are done, and the complexity is $O(n)$. In the second case, we are left with an array of size $\frac{n}{2}$, and we repeat the process. The total complexity is given by the recurrence relation:
$$T(n) = n + \frac{n}{2} + \frac{n}{4} + \cdots + 1$$
$$T(n) = n(1 + \frac{1}{2} + \frac{1}{4} + \cdots) = 2n = O(n)$$

### Worst case:

Worst case happens when the pivot is always the smallest/largest element (sorted array). In this case, we are left with an array of size $n-1$ after the first iteration, $n-2$, then $n-3$ and so on. The total complexity is given by the recurrence relation:
$$T(n) = n + (n-1) + (n-2) + \cdots + 1$$
$$T(n) = \frac{n(n+1)}{2} = O(n^2)$$

### Average case with random pivot:

A random pivot won't split the array into two equal halves, but it will land in the middle part (25% to 75%) haft of the time. In worst case of these "good splits", we are left with an array with the size of $\frac{3n}{4}$ elements from the original array. The recurrence relation is:

$$T(n) = n + T(\frac{3n}{4})$$

We can solve the problem with Master Theorem, where:
- a = 1
- b = 4/3
- f(n) = n

We have the recursive overhead as $n^{\log_{4/3} 1} = n^0 = 1$. Since $f(n) > n^{\log_{4/3} 1}$, we are in case 3 of the Master Theorem. Therefore, the total complexity is $T(n) = \Theta(n)$.

## Question 7

The randomized selection is used to find the smallest element of the array A[9, 1, 3, 0, 7, 5, 6, 8, 4, 2]. Describe a sequence of partitions that results in the worst case of the algorithm.

In order to get the worst case, the random pivot must always pick the largest element in the current array. The sequence of partitions is as follows:
1. Pivot = 9, partitioned array: [1, 3, 0, 7, 5, 6, 8, 4, 2] | 9
2. Pivot = 8, partitioned array: [1, 3, 0, 7, 5, 6, 4, 2] | 8
3. Pivot = 7, partitioned array: [1, 3, 0, 5, 6, 4, 2] | 7
4. And so on...

The final sequence of pivots will be: 9 → 8 → 7 → 6 → 5 → 4 → 3 → 2 → 1 → 0, where 0 is the required smallest element.

The probability of getting the worst case is $\frac{1}{10} \times \frac{1}{9} \times \cdots \times \frac{1}{2} = \frac{1}{10!}$, which is approximately $\frac{1}{3628800}$ or $0.0000276\%$.

## Question 8

In the deterministic selection algorithm, the input elements are divided into groups of 5 and calculate the median of each group. What are the complexities if the input elements are divided into:

### Group of 3:

In a group of 3, the median is larger than 1 element and smaller than 1 element (2 elements are ≤ the median, including itself). There are $\lceil\frac{n}{3}\rceil$ groups, and the median-of-medians is larger than at least half of these medians. This guarantees that the pivot is larger than at least $2 \times \frac{n}{6} = \frac{n}{3}$ elements. The worst case leaves us searching in the remaining $\frac{2n}{3}$ elements.
$$T(n) = T\left(\frac{n}{3}\right) + T\left(\frac{2n}{3}\right) + O(n)$$
In the recursion tree, every level still processes a total of $n$ elements (since $\frac{n}{3} + \frac{2n}{3} = n$). The height of the tree is determined by the larger branch, which is $O(\log_{3/2} n)$. Therefore, the total complexity is $O(n\log n)$.

### Group of 7:

In a group of 7, the median is larger than 3 elements (4 elements are ≤ the median, including itself). There are $\lceil\frac{n}{7}\rceil$ groups, and the median-of-medians is larger than at least half of these medians. This guarantees that the pivot is larger than at least $4 \times \frac{n}{14} = \frac{2n}{7}$ elements. The worst case leaves us searching in the remaining $\frac{5n}{7}$ elements.
$$T(n) = T\left(\frac{n}{7}\right) + T\left(\frac{5n}{7}\right) + O(n)$$
The total work at each recursive level is $\frac{n}{7} + \frac{5n}{7} = \frac{6n}{7}$, which is less than $n$, so the work shrinks geometrically. The total complexity is:
$$T(n) = n + \frac{6n}{7} + \left(\frac{6}{7}\right)^2 n + \cdots = \frac{n}{1 - \frac{6}{7}} = 7n = O(n)$$
